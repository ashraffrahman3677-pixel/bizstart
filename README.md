# EZBiz - AI Business Operating System for SMEs

**Status:** 🚀 Starting Phase 1 - Authentication Foundation

## Project Overview

EZBiz is a production-ready **AI Business Operating System** designed for Small and Medium Enterprises (SMEs).

### Technology Stack
- **Frontend:** Flutter + Dart
- **Backend:** Supabase + PostgreSQL
- **Architecture:** Clean Architecture + Repository Pattern
- **AI:** OpenAI Integration

## Setup Instructions

```bash
# Clone
git clone https://github.com/ashraffrahman3677-pixel/bizstart.git
cd bizstart

# Configure environment
cp .env.example .env
# Edit .env with credentials

# Install dependencies
flutter pub get

# Run
flutter run
```
